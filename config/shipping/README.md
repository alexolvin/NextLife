# Тарифы перевозчиков NextLife (Раздел III.2.1 ТЗ v2.0)

Каждый перевозчик описывается файлом `config/shipping/<carrier>.yaml`.

Обязательные требования:
1. Значения тарифов строго берутся из официальных источников. Выдумывание запрещено.
2. Каждая услуга (`service`) ОБЯЗАНА содержать `source_url` (ссылка на официальный прайс) и `fetched_at` (дата проверки/снятия тарифа).
3. Тариф без `source_url` или `fetched_at` не проходит валидацию при старте системы.
4. Если тариф старше `tariff_max_age_days` (по умолчанию 90 дней), он помечается устаревшим (`stale`) и требует обновления перед публикацией.
