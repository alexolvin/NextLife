NextLife — открытая платформа управления рекоммерцией и скилл OpenClaw для продажи и покупки подержанных товаров на вторичных торговых площадках.

---

## Возможности

- **Склад и предметы:** Управление вещами, разведка рыночных цен, описания, учёт дефектов и конструктор доставки в едином нелинейном интерфейсе.
- **Объявления на площадках:** Автоматическая подготовка объявлений, локализация категорий и переводов, обратимое утверждение и пакетное фоновое размещение.
- **Единые диалоги с покупателями:** Группировка переписок по предметам, генерация вариантов ответов через ИИ и синхронизация встреч с Notion Calendar.
- **Покупки и анализ комплектов:** Автоматизированный поиск предложений и оценка выгоды составных комплектов при перепродаже по частям.
- **Центр действий («Внимание»):** Приоритетная очередь задач: непрочитанные сообщения, ожидающие отправки посылки, подтверждения оплаты и истёкшие объявления.
- **Фоновый воркер и надёжность:** Асинхронная обработка очередей с каталогом инструкций по устранению ошибок и структурированными пакетными отчётами.
- **REST и OpenClaw API:** Полный JSON API и шлюз (`/api/oc/*`) для работы автономных кодовых агентов.

## Требования

- **Python:** 3.12 или новее
- **База данных:** PostgreSQL 14+ (или совместимая)
- **Операционная система:** Linux (с поддержкой systemd для служб) / macOS

---

## Аппаратные требования

- **Процессор (CPU):** от 2 ядер (рекомендуется 4 ядра)
- **Оперативная память (RAM):** от 4 ГБ (рекомендуется 8 ГБ для браузерной автоматизации)
- **Дисковое пространство:** от 10 ГБ для базы данных, медиа-файлов и журнала
- **Ускорители / GPU:** Не требуются (поддерживаются облачные OpenAI-совместимые API)

## Быстрый старт

```bash
# 1. Клонирование репозитория
git clone https://github.com/alexolvin/NextLife.git
cd NextLife

# 2. Настройка переменных окружения
cp .env.example .env

# 3. Создание виртуального окружения и установка зависимостей
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

# 4. Применение миграций базы данных
alembic upgrade head

# 5. Запуск веб-приложения
uvicorn nextlife.api.main:app --host 127.0.0.1 --port 8081
```

Веб-интерфейс доступен по адресу `http://127.0.0.1:8081/ui/stock`.

---

## Конфигурация

Параметры окружения задаются в файле `.env`:

| Переменная | Описание | Пример / По умолчанию | Обязательно |
|---|---|---|---|
| `NEXTLIFE_PORT` | HTTP-порт веб-службы | `8081` | Нет |
| `NEXTLIFE_DSN` | Строка подключения к PostgreSQL | `postgresql+psycopg2:///nextlife` | Да |
| `NEXTLIFE_WEB_TOKEN` | Секретный токен авторизации веб-сессий | `your_secret_token` | Да |
| `NEXTLIFE_OPENCLAW_TOKEN` | Bearer-токен для API OpenClaw | `your_oc_token` | Да |
| `NEXTLIFE_DATA_DIR` | Путь к директории хранения данных | `/var/lib/nextlife/data` | Да |
| `NEXTLIFE_MEDIA_DIR` | Путь к директории хранения медиа и фото | `/var/lib/nextlife/media` | Да |

## Использование

- **Веб-интерфейс:** Перейдите на `http://127.0.0.1:8081/`:
  - `/ui/stock` — Склад товаров и карточки предметов.
  - `/ui/listings` — Объявления на площадках и очереди размещения.
  - `/ui/messages` — Многоканальные диалоги с покупателями.
  - `/ui/buy` — Поиск выгодных покупок и расчёт комплектов.
  - `/ui/attention` — Центр внимания с задачами в порядке срочности.
  - `/ui/settings` — Профиль, возможности площадок и настройки ИИ.
- **Фоновый воркер:**
  ```bash
  python -m nextlife.jobs.worker
  ```

## Структура проекта

```text
NextLife/
├── alembic/              # Миграции схемы базы данных
├── config/               # Профили торговых площадок и конфигурация
├── docs/                 # Документация и отчёты об архитектуре
├── scripts/              # Эксплуатационные скрипты и скрипты деплоя
├── src/nextlife/
│   ├── api/              # Приложение FastAPI, маршруты и шаблоны
│   ├── comms/            # Синхронизация входящих и исходящих сообщений
│   ├── connectors/       # Адаптеры площадок и парсеры
│   ├── core/             # Конфигурация, статусы, доменные модели
│   ├── jobs/             # Фоновый воркер, каталог ошибок и отчёты
│   ├── media/            # Пайплайн обработки фото и ИИ-редактирование
│   ├── services/         # Бизнес-логика (склад, объявления, покупки, Notion)
│   └── storage/          # Модели SQLAlchemy и сессии базы данных
├── templates/web/        # Шаблоны интерфейса Jinja2 (mobile-first)
└── tests/                # Автоматизированные тесты pytest
```
