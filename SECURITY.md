# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in NextLife:

1. Please open a [GitHub Security Advisory](https://github.com/alexolvin/NextLife/security/advisories) (preferred).
2. Or contact the project maintainers via the contact options listed on the repository owner's GitHub profile.
3. Do not open public issues for undisclosed security vulnerabilities.

Please include:
- A description of the issue and potential impact
- Detailed reproduction steps or proof-of-concept
- Affected software version and environment details
