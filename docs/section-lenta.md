# Раздел «Лента» (/ui/items)

Основной экран приложения. Отображает список предметов (лотов) в виде карточек с возможностью фильтрации по статусу и быстрого поиска.

## Навигация

- **URL:** `/ui/items`
- **Пункт меню:** «Лента» (нижняя навигация + меню)
- **Активная вкладка:** `items`

---

## Элементы страницы

### 1. Заголовок

```
Лента предметов
```

Статичный заголовок `.page-title`.

### 2. Быстрый поиск

Поле ввода с `oninput="filterItems(this.value)"` — клиентская фильтрация карточек по подстроке в заголовке. Не обращается к серверу.

| Атрибут | Значение |
|---------|----------|
| Тип | `input[type=search]` |
| Placeholder | `🔍 Быстрый поиск предметов...` |
| aria-label | `Поиск предметов` |

### 3. Фильтры по статусу (filter-pills)

Чипы-переключатели, каждый ведёт на `/ui/items?status_filter=<STATUS>`:

| Чип | Query param | Описание |
|-----|-------------|----------|
| **Все** | *(отсутствует)* | Все предметы, кроме `CANCELLED` и `DELETED` |
| **Требуют утверждения** | `status_filter=AWAITING_APPROVAL` | Черновики, ожидающие утверждения |
| **Утверждены** | `status_filter=APPROVED` | Утверждённые предметы |
| **Черновики** | `status_filter=DRAFT` | Черновики |

Активный чип подсвечивается классом `.active`.

### 4. Сетка карточек (`.item-feed-grid`)

Адаптивная сетка карточек предметов. Сортировка: **по убыванию `created_at`** (новые сверху).

---

## Карточка предмета (`.item-feed-card`)

Каждая карточка содержит:

| Поле | Источник | Описание |
|------|----------|----------|
| **Код** | `item.code` | Бейдж `#<code>` (слева сверху) |
| **Статус** | `item.status` | Бейдж с русским названием и цветовой классацией (справа сверху) |
| **Миниатюра** | `thumb_url` | Первое логическое фото (цепочка). Если нет фото или файл бит — плейсхолдер `📦` |
| **Заголовок** | `item.title` | Ссылка на карточку `/ui/items/<code>` |
| **Цена** | `item.target_price` + `item.target_currency` | Форматированная сумма или «цена не задана» |
| **Фото** | `photo_count` | Количество логических фото (цепочек) |
| **Листинги** | `listings_count` | Количество активных объявлений на площадках |
| **Кнопка действия** | зависит от статуса | см. ниже |

### Кнопка действия на карточке

| Статус | Кнопка | Ссылка |
|--------|--------|--------|
| `AWAITING_APPROVAL` | «Проверить черновик →» | `/ui/draft/<code>` |
| остальные | «Карточка предмета →» | `/ui/items/<code>` |

### Пустое состояние

Если предметов нет:

```
Нет предметов в этой категории.
Создайте первый предмет, чтобы начать работу.
[Создать предмет] → /ui/wizard
```

## Карточка предмета (/ui/items/{code})

Детальная страница предмета. Содержит:

### Шапка

| Поле | Описание |
|------|----------|
| Кнопка «← Назад в ленту» | Ссылка на `/ui/items` |
| Код | Бейдж `#<code>` |
| Заголовок | `item.title` |
| Цена | `target_price` + `target_currency` или «цена не задана» |
| Статус | Бейдж с русским названием |
| Кнопка «Доставка» | `/ui/lots/<code>/shipping` |
| Кнопка «Правка» | `/ui/lots/<code>/edit` |

### Фотогалерея

- **Слайдер** — главный просмотр с кнопками ‹ ›, счётчиком `N / total`, тегом роли (Обработано / Дефект / Оригинал)
- **Лента миниатюр** (`.thumb-strip`) — горизонтальная прокрутка, клик переключает слайд
- **Бейджи на миниатюрах:**
  - «обработано» — роль `PUBLISH`/`PROCESSED`
  - «обложка» — `is_cover`
  - «AI» — изображение изменено генеративно
  - «🚫 файл не найден» — битое фото (плейсхолдер, без 404)
- **Кнопка удаления** `×` на каждой миниатюре (с `confirm`)

#### Операции над активным фото

| Кнопка | Действие | Скрыто для |
|--------|----------|------------|
| ⟳ Повернуть | Поворот на 90° | — |
| ▦ Фон | Нормализация фона | фото дефекта |
| ✦ Пыль | Удаление пыли и засветов | фото дефекта |
| ★ Обложка | Сделать обложкой лота | — |
| ⚑ Дефект | Пометить как фото дефекта | — |

Все операции создают **новую версию** фото; оригинал неизменён.

#### Подсказки по качеству

После загрузки фото система может показать предупреждения (например, «низкое разрешение», «переэкспонировано») в блоке `💡 Подсказки по качеству`.

#### Предпросмотр на площадках

| Кнопка | URL |
|--------|-----|
| Bazoš.cz | `/ui/items/<code>/preview/bazos_cz` |
| Sbazar.cz | `/ui/items/<code>/preview/sbazar_cz` |
| Aukro.cz | `/ui/items/<code>/preview/aukro_cz` |
| ↻ Догенерировать | `POST /ui/items/<code>/photos/regen-variants` |

### Загрузка фотографий

Форма `multipart/form-data`:

| Поле | Тип | Описание |
|------|-----|----------|
| Файлы | `file[multiple]` | JPEG, PNG, WebP |
| Тип снимков | `select` | `ORIGINAL` (Оригинал) / `DEFECT` (Дефект) |

### Дефекты

Красный блок с перечнем реальных дефектов. Каждый дефект: зона (бейдж) + текст + ссылка на фото.

### Особенности

Слаightly-блок с позитивными характеристиками (не дефекты).

### Текстовые блоки объявления

| Блок | Описание | Редактируемый |
|------|----------|---------------|
| 📝 Заметки оператора | Внутренние заметки, видны только оператору | Нет |
| ✨ Сгенерированное описание | LLM-черновик текста объявления | Через `/ui/draft/<code>` |
| 📋 Финальный текст | Утверждённый текст для публикации | Да (textarea + «Сохранить») |

> ⚠️ Изменение финального текста требует повторного утверждения.

### Доставка и тарифы

Кнопка «Настроить →» ведёт на `/ui/lots/<code>/shipping` (калькулятор Zásilkovna, Balíkovna, PPL).

### Разведка рынка (research)

Панель аналогов с ценами на других площадках.

### Лента событий (audit)

Свёрнутый служебный блок `<details>` с историей действий:

```
<дата> | <действие> (<актор>)
```

## Статусы предмета

| Статус | Русское название | Видим в ленте «Все» |
|--------|-----------------|---------------------|
| `DRAFT` | Черновик | ✅ |
| `AWAITING_APPROVAL` | Требует утверждения | ✅ |
| `APPROVED` | Утверждён | ✅ |
| `PUBLISHED` | Опубликован | ✅ |
| `RESERVED` | Зарезервирован | ✅ |
| `SOLD` | Продан | ✅ |
| `CANCELLED` | Отменён | ❌ |
| `DELETED` | Удалён | ❌ |

## API / маршруты

| Метод | URL | Назначение |
|-------|-----|-----------|
| GET | `/ui/items` | Лента предметов (HTML) |
| GET | `/ui/items?status_filter=<STATUS>` | Фильтр по статусу |
| GET | `/ui/items/{code}` | Карточка предмета (HTML) |
| POST | `/ui/items/{code}/photos/upload` | Загрузка фото |
| POST | `/ui/items/{code}/photos/{id}/delete` | Удаление фото |
| POST | `/ui/items/{code}/photos/rotate` | Повернуть фото |
| POST | `/ui/items/{code}/photos/clean-bg` | Чистка фона |
| POST | `/ui/items/{code}/photos/remove-dust` | Удаление пыли |
| POST | `/ui/items/{code}/photos/cover` | Сделать обложкой |
| POST | `/ui/items/{code}/photos/defect` | Пометить дефект |
| POST | `/ui/items/{code}/photos/regen-variants` | Догенерировать варианты |
| GET | `/ui/items/{code}/preview/{mp_key}` | Предпросмотр на площадке |
| POST | `/ui/draft/{code}/update` | Обновить финальный текст |
