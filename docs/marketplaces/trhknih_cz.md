# TrhKnih.cz (`trhknih_cz`) — план подключения

Решение (ТЗ M1 A.2): максимальный набор, **только категория «книги»**. Канал `DIRECT` по всем сценариям. Старт — A5.

**Живая проба 2026-10-03**: `https://www.trhknih.cz/hledat?q=python` → 200, без антибота, SSR: 8 книг (`/kniha/...`). Артефакт: `.a/reports/m1/probes/2026-10-03/trhknih_cz.html`.

Канал по сценариям: поиск `DIRECT` / публикация `DIRECT` / правка цены `DIRECT` / снятие `DIRECT` / переписка `DIRECT` / состояние сделки `DIRECT`

Доступы от Владельца: учётная запись TrhKnih (при наличии подтверждений — Владельцем).

Технические шаги: по шаблону Bazoš:
1. Живая проба маршрутов поиска и карточки, сырой HTML с датой;
2. Карта маршрутов и селекторы в `config/marketplaces/trhknih_cz.yaml`; **в реестре площадки — ограничение по категории «книги»**;
3. Фикстуры + контрактные тесты; **тест: лот другой категории (напр. «электроника») на эту площадку не предлагается — отказ** (мутация D.3-8);
4. Канарейка;
5. Публикация/правка/снятие/переписка — Playwright в сессии Владельца.

Покрытие сценариев: полный цикл, но только для лотов категории «книги». Не покрывается: лоты других категорий — площадка для них не предлагается (проверяется тестом).

Верификация: пробы с датой, фикстуры, тест категорийной фильтрации, канарейка, `external_url` + снимок (Ч-5).

Риски: узкая ниша (смысловое); смена вёрстки — канарейка.

Усилия: S

Зависимости: закрытие минимального набора (A1+A2); учётная запись Владельца.

Класс блокировки: нет (канал работает на живую).
