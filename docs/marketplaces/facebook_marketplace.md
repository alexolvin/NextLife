# Facebook Marketplace (`facebook_marketplace`) — план подключения

Решение (ТЗ M1 A.2): максимальный набор, подключается **последним** — только после того, как Vinted отработал не менее 14 дней без `BLOCKED` по причине площадки. Канал `ANDROID` по всем сценариям.

**Живая проба 2026-10-03**: `https://www.facebook.com/marketplace/prague/search?query=thinkpad` → **HTTP 400** (Meta блокирует прямой доступ / login wall). Артефакт: `.a/reports/m1/probes/2026-10-03/facebook_marketplace.html`, `summary.json`.

Канал по сценариям: поиск `ANDROID` / публикация `ANDROID` / правка цены `ANDROID` / снятие `ANDROID` / переписка `ANDROID` / состояние сделки — вне площадки (оплата и доставка не проходят через Facebook, по общим правилам NextLife)

Доступы от Владельца: приложение Facebook на выделенном телефоне, залогиненное самим Владельцем; принятие риска (подтверждение 7); суточный лимит `daily_cap` — стартовое значение задаёт Владелец (подтверждение 8); письменное согласие на тестовую публикацию с конкретным лотом (подтверждение 9).

Технические шаги: по тем же компонентам, что Vinted (мост общий, B.2–B4 уже будут готовы); отдельный пакет:
1. Распознаватель экранов Facebook Marketplace (эталоны: выдача поиска, карточка, форма подачи, чат);
2. `app_state`, `search`, `read_listing` (итерация 1);
3. `create_listing`, `update_price`, `archive_listing` (итерация 2, отдельное согласие на лот);
4. `read_inbox`, `read_thread`, `send_message` (итерация 3);
5. Канарейка Facebook.

Покрытие сценариев: поиск, чтение, публикация, переписка. Не покрывается: встроенная оплата/доставка — их у Facebook в ЧР нет; состояние сделки ведётся по общим правилам NextLife (подтверждения сторон, доказательства).

Верификация: доказательства моста (B.3) + `external_url`/снимок публикации (Ч-5) + канарейка.

Риски:
- **наибольший риск ограничения учётной записи в наборе** — объём не более `daily_cap` действий в сутки из конфига; темп человеческий; все действия утверждаются Владельцем;
- блокировки/проверки личности — неизвестный экран → `BLOCKED` со снимком, мост не проходит проверки (B.3, п.3);
- смена верстки приложения → `BLOCKED` до канарейки.

Усилия: L

Зависимости: Vinted стабилен ≥ 14 дней без `BLOCKED` по причине площадки; телефон и adb-узел (подтверждения 5, 6); до этого — `BLOCKED-EXTERNAL`.

Класс блокировки: `DIRECT` — навсегда (login wall Meta, факт пробы 2026-10-03); `ANDROID` — снимается ресурсом (телефон + учётная запись + принятие риска).
