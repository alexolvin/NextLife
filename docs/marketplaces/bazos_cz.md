# Bazoš.cz (`bazos_cz`) — план подключения

Решение (ТЗ M1 A.2): минимальный набор. Канал `DIRECT` по всем сценариям.

**Живая проба 2026-10-03**: HTTP 200, без антибота, final URL = запрошенный (`https://www.bazos.cz/search.php?hledat=thinkpad`), извлечено 20 объявлений с ценами. Артефакты: `.a/reports/m1/probes/2026-10-03/bazos_cz.html`, `summary.json`.

Канал по сценариям: поиск `DIRECT` (работает) / публикация `DIRECT` / правка цены `DIRECT` / снятие `DIRECT` / переписка `DIRECT` / состояние сделки `DIRECT`

Доступы от Владельца: учётная запись Bazoš; телефонный номер для подтверждения объявлений (код из SMS запрашивается у Владельца через Telegram и вводится им самим — NextLife SMS не перехватывает).

Технические шаги:
1. Зафиксировать текущие селекторы живой пробой (выполнено 2026-10-03: `.inzeraty` — карточка, `.inzeratycena` — цена; оба актуальны).
2. Записать фикстуры: выдача поиска, карточка объявления, форма подачи (с датой записи).
3. Playwright-профиль сессии Владельца (вход один раз — Владельцем).
4. Реализовать публикацию, правку цены, снятие, чтение состояния объявления.
5. Подтверждающий SMS-код — через Telegram, вводит Владелец.
6. Канарейка канала (часть D) с запросом из конфига.

Покрытие сценариев: после шага 1 работает поиск и разведка (уже в проде, 20 листингов на живую). После шагов 3–4 — полный цикл ТЗ: публикация с доказательством (Ч-5: `external_url` + снимок), правка цены, снятие, переписка, состояние. Не покрывается: ничего — у Bazoš есть все сценарии.

Верификация: фикстуры поиска/карточки/формы (CI); живая проба с датой и сырым HTML (статус); публикация — `external_url` + PNG опубликованного объявления; канарейка — ежедневный артефакт.

Риски:
- лимиты площадки на число объявлений и частоту подачи — коннектор останавливается с `BLOCKED` и причиной, не ретраит вслепую;
- платное поднятие объявлений — только по явному решению Владельца (Ч-7);
- смена вёрстки — канарейка ловит дрейф схемы, канал в `BLOCKED` до ремонта.

Усилия: S

Зависимости: учётная запись Владельца + номер телефона (подтверждения 2 и 3); после подтверждения — без внешних блокировок.

Класс блокировки: публикация — снимается ресурсом (учётная запись + номер). Поиск — нет.
